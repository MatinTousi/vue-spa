# Vue SPA

A simple Single Page Application built with **Vue 3** and **Vite**.

## 🚀 Features

- Fetches data from the JSONPlaceholder API
- Displays data dynamically in the UI
- Add new items locally for demonstration purposes
- Responsive design using Bootstrap
- Component-based architecture with Vue 3

## 🛠️ Technologies

- Vue 3
- Vite
- Bootstrap 5
- JavaScript
- CSS
- JSONPlaceholder API

## 📌 Notes

This project uses the JSONPlaceholder API as a mock backend for fetching data.

The add functionality is implemented for demonstration purposes only. New items are stored locally in the application and are not permanently saved to the API.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/vue-spa.git
```

Navigate to the project folder:

```bash
cd vue-spa
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
